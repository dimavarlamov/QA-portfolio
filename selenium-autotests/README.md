## UI автотесты (Selenium + Java)

Автотесты проверяют ключевую функциональность веб-приложения AutoSales.

📁 Папка: [selenium-autotests](./selenium-autotests/)

### Что покрыто автотестами

**Регистрация**
- Успешная регистрация с валидными данными
- Регистрация с пустыми полями 
- Регистрация с невалидным email
- Регистрация с уже существующим email

**Авторизация**
- Успешный вход с валидными данными
- Вход с неверным паролем
- Выход из аккаунта

**Каталог**
- Поиск по несуществующему запросу – сообщение «Автомобили не найдены»
- Поиск существующего автомобиля 
- Поиск с XSS-строкой – безопасность
- Поиск с невалидными символами
- Сброс фильтров 
- Некорректный диапазон цены (min > max) 
- Фильтр по цене 
- Фильтр по марке 
- Фильтр по стране производителя
- Фильтр по рулю 
- Фильтр по типу двигателя 
- Фильтр по кузову 
- Фильтр по цвету 
- Фильтр по кондиционеру
- Комбинация фильтров
  
**Карточка автомобиля**
- Открытие карточки, проверка данных )
- Карточка автомобиля без наличия 
- Добавление в избранное из карточки
- Удаление из избранного из карточки

**Избранное**
- Добавление автомобиля в избранное 
- Удаление автомобиля из избранного
- Быстрые клики по кнопке избранного 

**Покупка**
- Успешная покупка автомобиля
- Проверка, что заказ появился в разделе «Мои покупки»

**Безопасность**
- Обычный пользователь не может зайти в админ-панель
