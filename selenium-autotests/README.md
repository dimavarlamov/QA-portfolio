## UI автотесты (Selenium + Java)

Автотесты проверяют ключевую функциональность веб-приложения AutoSales.

📁 Папка: [selenium-autotests](./selenium-autotests)

### Что покрыто автотестами

- **Регистрация** – валидные/невалидные данные, дубликат email
- **Авторизация** – успешный вход, неверный пароль, выход
- **Каталог** – поиск, сброс фильтров, фильтрация по цене, марке, стране, типу двигателя, кузову, цвету, кондиционеру
- **Карточка автомобиля** – отображение данных, добавление/удаление из избранного
- **Избранное** – добавление, удаление, защита от дублей
- **Покупка** – успешная покупка, появление заказа в «Моих покупках»
- **Безопасность** – недоступность админки для обычного пользователя

###

### Запуск тестов

cd selenium-autotests
mvn clean test
